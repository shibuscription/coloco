# coloco

coloco（カラコ）は、PCCS 色立体を 3D 空間で可視化し、色相・明度・彩度の関係を触りながら理解するための教材アプリです。  
現在は Phase 1 の PCCS 3D ビューア、Phase 2 の画像解析、Phase 3 初版のライブカメラ解析まで実装が進んでいます。

3D 上の色配置を観察するだけでなく、画像やカメラ映像の色を PCCS に直接分類し、3D 色立体と行き来しながら学べる構成になっています。

## できること

### Phase 1: PCCS 3D ビューア

- 3D 空間で PCCS 色立体を点群表示する
- ドラッグ / スワイプで回転、上下方向の操作でチルト、ホイール / ピンチでズームする
- 色点をクリック / タップして色情報を表示する
- トーン強調、色相強調、無彩色強調を切り替える
- PCCS 全色から好きな色を複数選んで強調表示する
- 同一トーン / 同一色相 / 同一明度の補助線を個別に表示する
- PC / スマホのレスポンシブ UI で操作する

### Phase 2: 画像解析と 3D 連動

- 画像を読み込んで PCCS 直接分類を行う
- 各ピクセルを Lab 距離で最寄りの PCCS 色へ割り当てる
- PCCS 色ごとの比率を集計し、面積順にカラータイル表示する
- タイル選択に応じて、3D 色立体の強調表示を即時に切り替える
- 画像上のクリック位置がどの PCCS 色に分類されたかを参照する
- 選択中カラーの構成比を横棒の積み上げバーで確認する

### Phase 3 初版: ライブカメラ解析

- 画像解析パネルからカメラを起動する
- ライブ映像を一定間隔で解析し、PCCS カラータイルをリアルタイム更新する
- 撮影ボタンで、その瞬間のフレームを静止画像として確定する
- 撮影後は通常の画像解析フローへ合流し、既存 UI をそのまま使う
- モバイルでは前面 / 背面カメラを切り替えられる

## 3D ビュー操作

- 3D ビューは、手動操作と自動回転の両方に対応しています。
- 自動回転は 3 トグルです。
  - 右回り
  - 左回り
  - OFF
- ボタンを押すたびに `右回り → 左回り → OFF → ...` と循環します。
- 手動操作中は自動回転を一時停止し、操作後に必要に応じて再開します。
- 基準方位固定を ON にすると、PCCS の基準方位にそろえた状態で水平方向の回転を固定し、チルトとズームだけを有効にできます。

## 設定モーダル

設定モーダルでは、表示や回転に関する設定をまとめて変更できます。

### 球サイズ

- 設定モーダルの最上部に `球サイズ` スライダーがあります。
- 左へ動かすと球が小さくなり、右へ動かすと大きくなります。
- 初期値は現状サイズで、最大側になっています。
- 球サイズを変えても、選択中の球ハイライトは通常サイズに対する相対倍率で拡大するため、不自然に大きく見えないようにしています。

### 回転速度

- 設定モーダルから `回転速度` を調整できます。
- 単位は `rpm` です。
- スライダーは左で遅く、右で速くなります。
- 範囲は `0.5 rpm` から `6.0 rpm`、初期値は `1.0 rpm` です。
  - `1.0 rpm` は約 1 分で 1 周に相当します。
- 自動回転が OFF のときは、回転速度スライダーは非活性になります。
- 回転を再開すると、保持していた速度でそのまま再開します。

### 強調表示

- トーン強調と色相強調はカスタムドロップダウンで切り替えます。
- トーン強調と色相強調は排他的です。
- 画像由来強調も別枠で扱い、トーン / 色相強調とは同時に有効にならないようにしています。
- 複数選択強調は、左上の専用パネルから PCCS 全色を複数選んで使います。
- 複数選択強調で 1 色でも選択すると、トーン強調 / 色相強調 / 画像由来強調は解除されます。
- `全解除` で複数選択強調の選択状態をすべてクリアし、通常表示に戻せます。
- 複数選択強調パネルのタイルは、クリック / タップに加えて長押しドラッグで連続選択 / 解除できます。
- 色タイル一覧は、`p / lt / b / v奇数 / v偶数 / dp / dk / dkg / ltg / sf / s / d / g` の順に並び、最下段に無彩色 5 色を表示します。

## 下部の色相ラベル

- 3D 表示下部の円周上ラベルは、PCCS の 24 色相を表示しています。
- 表記は番号付きです。例:
  - `2:R`
  - `10:YG`
  - `24:RP`
- ラベルは円周に沿って配置され、3D 回転に追従します。
- 現在の表示は以下の 24 色相です。
  - `1:pR`
  - `2:R`
  - `3:yR`
  - `4:rO`
  - `5:O`
  - `6:yO`
  - `7:rY`
  - `8:Y`
  - `9:gY`
  - `10:YG`
  - `11:yG`
  - `12:G`
  - `13:bG`
  - `14:BG`
  - `15:BG`
  - `16:gB`
  - `17:B`
  - `18:B`
  - `19:pB`
  - `20:V`
  - `21:bP`
  - `22:P`
  - `23:rP`
  - `24:RP`

## 色相強調

- 色相強調ドロップダウンの表示は、番号付き表記です。
  - 例: `14:BG（青緑）`
- 表示ラベルと内部値は分離しています。
- 表示ラベルはユーザー向けの文字列で、内部では一意な色相番号を使って判定しています。
- そのため、同じ記号を含む近接色相までまとめて強調しません。
  - `14:BG` を選んでも `15:BG` 側は強調しません。
  - `18:B` を選んでも `17:B` 側は強調しません。

## ドロップダウン表示ラベル

- トーン強調や色相強調のドロップダウンは、日本語付きラベルで表示します。
  - `v（ビビッド）`
  - `b（ブライト）`
  - `2:R（赤）`
  - `24:RP（赤紫）`
- 表示用ラベル文字列は UTF-8 前提で管理しています。
- 文字化けを避けるため、内部値 `value` と表示文字列 `label` を分けて扱っています。

## 補助線

補助線は設定モーダル内で、種類ごとに個別に ON / OFF できます。

- `同一トーン`
  - 各トーンの色相列を結ぶ閉曲線です。`v` は 24 色相、その他は 12 色相代表を使います。
- `同一色相`
  - 偶数番号色相ごとの縦曲線です。
- `同一明度`
  - 経線と高さ一定面の交点から作る水平断面線です。

緯線・経線・同一明度線はいずれも、なめらかな曲線形状を維持したまま、近傍の球色に基づくグラデーションで描画しています。

## 色情報パネル

- 色点を選ぶと、右下またはモバイル向けフローティング位置に色情報パネルを表示します。
- 表示項目:
  - PCCS 記号
  - マンセル記号
  - HEX
  - RGB
  - CMYK
- 各項目には個別のコピーボタンがあります。
- スマホでは折りたたみ表示に対応しており、初期状態はカラーバー中心の簡略表示です。
- 展開すると詳細情報を表示できます。
- 色情報パネル上ではスワイプで近傍色へ移動できます。
  - 左右: 同一トーン内で色相移動
  - 上下: 近いトーンへ移動

## 画像解析の仕組み

Phase 2 の画像解析は、一般的な代表色抽出をしてから PCCS に寄せる方式ではありません。  
画像内の各ピクセルを、最初から PCCS 161 色のどれかに直接分類しています。

- 解析前に画像を必要に応じて縮小する
- 小さい画像は無理に拡大しない
- 表示用サムネイルと解析用縮小は分けている
- 解析用縮小では補間ではなく、多数決ベースで元画像領域の代表 RGB を選ぶ
- 各ピクセルの色と PCCS 各色の近さ判定には Lab 距離を使う

この方式により、画像を「PCCS で読む」ための分類結果を、そのまま 3D 色立体へ対応づけられます。

## ライブカメラ解析

Phase 3 では、画像解析パネルにライブカメラ解析モードを追加しています。

- `カメラ起動` からライブ映像を表示する
- 一定間隔で軽量解析し、下部の PCCS カラータイルを更新する
- `撮影` すると、そのフレームを静止画像として確定する
- 撮影後は通常の画像解析フローへ合流する
- プレビューに見えている範囲と、ライブ解析 / 撮影の対象範囲が一致するように crop をそろえている
- モバイルでは前面 / 背面カメラ切り替えに対応している

初版実装としてライブ解析・撮影・通常解析への合流までは入っていますが、更新頻度や UI の磨き込み、ブラウザ差異やパフォーマンス調整には今後の改善余地があります。

## データ構成

現在の PCCS 表示対象は合計 `161` 点です。

- `v` トーン: 24 色相 = 24 点
- その他 11 トーン: 12 色相代表 = 132 点
- 無彩色: 5 点

描画座標に使うのはマンセル値ではなく、PCCS 記号由来の明度・彩度です。

- 描画用
  - 色相
  - PCCS 明度
  - PCCS 彩度
- 表示用
  - HEX
  - RGB
  - CMYK
  - 色名
  - マンセル記号

## 座標の考え方

coloco の 3D 座標は、極座標ベースで次のように構成しています。

- 色相 = 角度
- PCCS 明度 = 縦軸
- PCCS 彩度 = 半径

概念式:

```ts
x = pccsSaturation * chromaScale * cos(theta)
z = pccsSaturation * chromaScale * sin(theta)
y = pccsLightness * verticalScale
```

- `theta` は 24 色相定義の `angleDeg` を使う
- 無彩色は `pccsSaturation = 0` として中心軸上に配置する
- 表示色には `hex / rgb` を使う
- 明度方向はわずかに強調し、彩度方向はやや抑えて全体のまとまりを調整している

## UI の見方

- 左上: 画像解析パネルの開閉
- 左上の画像解析ボタンの右: 複数選択強調パネルの開閉
- 右上: 強調設定パネルの開閉
- 上部中央: 仮ロゴとして `coloco` のワードマークを表示
- 右下またはモバイル上部: 選択中の色情報パネル
- 複数選択強調パネル:
  - PCCS 全色と無彩色 5 色の一覧
  - 複数選択による 3D 強調
  - 長押しドラッグ連続選択
  - `全解除`
- 強調パネル内:
  - 球サイズ
  - 回転速度
  - 自動回転
  - 基準方位固定
  - 強調設定
  - 補助線表示

PC では画像解析パネルと強調パネルをフローティング表示し、背後の 3D を操作できます。  
スマホではオーバーレイ寄りの UI を使い分けています。

## プロジェクト構成

主要なファイル / フォルダは以下です。

- `src/data`
  - PCCS 色相定義、有彩色点、無彩色点、表示色、データメモ
- `src/components`
  - 3D シーン、色点描画、色情報カード、強調表示 UI、画像解析パネル、ガイド線、仮ロゴ
- `src/utils/pccs3d.ts`
  - PCCS データから 3D 座標を計算
- `src/utils/highlight.ts`
  - 強調表示の判定ロジック
- `src/utils/color.ts`
  - RGB / Lab 変換と色距離計算
- `src/utils/imageClassification.ts`
  - 画像解析、PCCS 直接分類、分類結果の集計
- `src/utils/pccsNavigation.ts`
  - 色情報パネル上の移動ロジック
- `src/constants/viewConfig.ts`
  - カメラやスケール係数などの描画設定
- `src/App.tsx`
  - アプリ全体のレイアウトと状態管理
