# coloco

coloco（カラコ）は、PCCS 色立体を 3D 空間で可視化し、色相・明度・彩度の関係を触りながら理解するための教材アプリです。  
現在は Phase 1 の PCCS 3D ビューアに加えて、Phase 2 初期実装として画像解析機能も入っており、画像内の色を PCCS 色へ直接分類しながら 3D 色立体と行き来して学べる状態になっています。

## できること

### Phase 1: PCCS 3D ビューア

- 3D 空間で PCCS 色立体を点群表示する
- ドラッグ / スワイプによる回転
- 上下操作によるチルト
- ホイール / ピンチによるズーム
- 自動回転の ON / OFF を切り替えられる
- PCCS立体の基準方位として、真上視点で Y（イエロー）が12時方向に来る向きへ固定できる
- 色点の選択と色情報表示
- 色情報パネル上のスワイプで近傍色へ移動できる
- トーン / 色相 / 無彩色の強調表示
- 立体ガイド線の ON / OFF を切り替えられる
- PC / スマホのレスポンシブ対応

### Phase 2 初期実装: 画像解析と 3D 連動

- 画像を読み込んで色解析できる
- 表示用サムネイルと解析用縮小を分けて扱う
- 画像を必要に応じて縮小してブラウザ内で解析する
- 各ピクセルを Lab 距離で最寄りの PCCS 色へ直接分類する
- PCCS 色ごとの比率を集計し、面積順にタイル表示する
- 画像読み込み直後は、構成比 1.0%以上の色を初期選択する
- タイル選択に応じて、3D 色立体の強調表示が即時に切り替わる
- 画像由来強調は、トーン強調 / 色相強調と排他的に扱われる
- 画像サムネイル上のクリック位置が、どの PCCS 色に分類されたか参照できる
- サムネイルクリックから、対応タイル・3D 球・色情報パネルまで連動して詳細確認できる
- 選択中カラーの構成比を横棒の積み上げバーで確認できる
- 未読み込み時は市松模様のプレースホルダーを表示し、サムネイル領域クリックから画像を選択できる
- 読み込み後はサムネイル右上のアイコンから画像をクリアできる
- PC では左右パネルをフローティング表示したまま 3D を操作できる
- スマホでもオーバーレイ UI としてレスポンシブに使える

## データ構成

現在の PCCS 表示対象は合計 `161` 点です。

- `v` トーン: 24 色相 = 24 点
- その他 11 トーン: 12 色相代表 = 132 点
- 無彩色: 5 点

Phase 1 では、`v` は 24 色相、その他 11 トーンは 12 色相代表で扱う代表構成を採用しています。

描画座標に使うのはマンセル値ではなく、PCCS 記号由来の明度・彩度です。

- 描画用
  - 色相
  - PCCS 明度
  - PCCS 彩度
- 表示用
  - HEX
  - RGB
  - 色名
  - マンセル記号

マンセル記号は情報表示用の補助データとして保持しており、座標計算には使いません。

## 座標の考え方

coloco の 3D 座標は、極座標ベースで次のように構成しています。

- 色相 = 角度
- PCCS 明度 = 縦軸
- PCCS 彩度 = 半径

概念式:

```ts
x = pccsSaturation * chromaScale * cos(theta)
z = pccsSaturation * chromaScale * sin(theta)
y = pccsLightness * verticalScale
```

- `theta` は 24 色相定義の `angleDeg` を使う
- 無彩色は `pccsSaturation = 0` として中心軸上に配置する
- 表示色には `hex / rgb` を使う
- 明度差や無彩色軸が読み取りやすいよう、縦方向のスケールはわずかに強調している
- 彩度方向の半径はやや抑えて、全体のまとまりが見やすいように調整している
- 立体ガイド線を ON にすると、各トーンの閉曲線と偶数色相の縦曲線を表示し、色立体の構造を追いやすくしている

## 画像解析の仕組み

Phase 2 の画像解析は、一般的な代表色抽出をしてから PCCS に寄せる方式ではありません。  
画像内の各ピクセルを、最初から PCCS 161 色のどれかに直接分類しています。

- 表示用サムネイルと解析用縮小は別ロジックで扱う
- 表示用サムネイルは見た目優先で生成する
- 解析前に画像を必要に応じて縮小する
- 小さい画像は無理に拡大しない
- 解析用縮小は通常の補間縮小ではなく、縮小後ピクセルに対応する元画像領域の RGB 多数決で色を決める
- そのため、縮小時に不要な中間色が新規生成されにくく、縮小後の色集合は元画像色の部分集合になりやすい
- 各ピクセルの色と PCCS 各色の近さ判定には Lab 距離を使う
- その結果、画像を「PCCS で読む」ための分類結果が得られる

この方式により、教材画像・ベタ塗り画像・配色見本のような色面が明確な画像でも、元画像の色系統を保ったまま、画像内にどの PCCS 色がどのくらい含まれているかを 3D 色立体と同じ基準でそのまま見られます。

## UI の見方

- 左上: 画像解析パネルの開閉
- 右上: 強調設定パネルの開閉
- 上部中央: 仮ロゴとして `coloco` のワードマークを表示
- 強調パネル上部: 3Dビュー補助操作（自動回転 ON/OFF、基準方位固定、立体ガイド線）
- 右下: 選択中の色情報パネル
- 画像解析タイルを選ぶと、3D 強調表示が即時に切り替わる

PC では左右パネルをフローティング表示し、パネルを開いたまま背後の 3D を操作できます。  
スマホではオーバーレイ寄りの UI として扱っています。  
スマホの色情報パネルは省スペースのため折りたたみ可能で、初期状態はカラーバー中心の簡略表示、トグルで `PCCS記号 / マンセル記号 / HEX / RGB` を展開できます。

## 使い方

### 3D ビュー

- ドラッグ / スワイプで色立体を回転
- 上下方向の操作でチルト
- マウスホイール / ピンチでズーム
- 強調パネル上部のボタンで自動回転の ON / OFF を切り替えられる
- 強調パネル上部の方位ボタンで、真上視点で Y（イエロー）が12時方向に来る基準方位へ固定できる
- 基準方位固定 ON 中は水平回転せず、チルトとズームだけを調整できる
- 強調パネル上部のガイド線ボタンで、各トーンの緯線と偶数色相の経線を表示 / 非表示できる
- 色点をクリック / タップすると色情報カードを表示
- 色情報パネル上の左右スワイプで、同じトーン内の隣の色相へ移動できる
- 色情報パネル上の上下スワイプで、色相をなるべく保ちながら隣のトーンへ移動できる
- トーン移動は循環し、`v` まで行くと `dkg`、`dkg` まで行くと `v` へ移る
- 色情報パネルの `PCCS記号 / マンセル記号 / HEX / RGB` は個別にコピーできる
- 強調表示 UI でトーン / 色相 / 無彩色を切り替え

初期状態では色立体がゆっくり自動回転し、操作中は停止、操作終了後に再開します。

### 画像解析

- 左上アイコンから画像解析パネルを開く
- 未読み込み時は市松模様のサムネイル領域をクリック / タップして画像を選べる
- 画像を読み込むと、PCCS 分類結果がタイル一覧で表示される
- 画像読み込み直後は、構成比 1.0%以上の色が初期選択され、そのまま 3D 強調と構成比バーへ反映される
- タイルの選択 / 解除は 3D 側へ即時反映される
- サムネイル上をクリック / タップすると、その位置がどの PCCS 色に分類されたか参照できる
- サムネイルクリック時は、対応タイルの参照ハイライトに加えて 3D 球の選択と色情報表示にも連動する
- 読み込み後はサムネイル右上のアイコンから画像をクリアできる
- PC ではタイルのダブルクリックで、その色の色情報を詳細表示できる

## 補助線の種類

強調パネル内の `補助線表示` では、補助線を種類ごとに個別に切り替えられます。

- `同一トーン`
  - 各トーンの色相列を結ぶ閉曲線です。`v` は 24 色相、その他は 12 色相代表で描画します。
- `同一色相`
  - 偶数色相ごとの縦曲線です。`W → p → lt → b → v → dp → dk → dkg → Bk` をなめらかに結びます。
- `同一明度`
  - 同一色相の縦曲線と、高さ一定の水平面との交点から作る水平断面線です。PCCS 立体を明度ごとに輪切りにした見え方を補助します。
