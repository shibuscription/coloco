# coloco

coloco（カラコ）は、PCCS 色立体を 3D 空間で可視化し、色相・明度・彩度の関係を触りながら理解するための教材アプリです。  
現在は Phase 1 の PCCS 3D ビューア、Phase 2 の画像解析、Phase 3 初版のライブカメラ解析まで進んでおり、3D 表示と画像解析を行き来しながら PCCS で色を読む体験を扱えます。

## できること

### Phase 1: PCCS 3D ビューア
- 3D 空間で PCCS 色立体を点群表示する
- ドラッグ / スワイプで回転、上下操作でチルト、ホイール / ピンチでズームする
- 色点をクリック / タップして色情報パネルを表示する
- 色情報パネル上の左右スワイプで同一トーン内の隣の色相へ、上下スワイプで隣のトーンへ移動する
- 自動回転を `右回り → 左回り → OFF` の 3 トグルで切り替える
- 基準方位固定を ON にすると、Y（イエロー）基準の方位に固定したままチルトとズームだけを行う
- 補助線を `同一トーン / 同一色相 / 同一明度` ごとに個別表示する
- PCCS 全色から任意の色を複数選び、既存強調と同じ見た目でまとめて強調する
- PC / スマホのレスポンシブ UI に対応する

### Phase 2: 画像解析と 3D 連動
- 画像を読み込んで色解析できる
- 画像を必要に応じて縮小してブラウザ内で解析する
- 各ピクセルを Lab 距離で最寄りの PCCS 色へ直接分類する
- PCCS 色ごとの比率を集計し、面積順にタイル表示する
- タイル選択に応じて、3D 色立体の強調表示が即時に切り替わる
- 画像由来強調は、トーン強調 / 色相強調と排他的に扱われる
- 画像サムネイル上のクリック位置が、どの PCCS 色に分類されたか参照できる
- 選択中カラーの構成比を横棒の積み上げバーで確認できる
- PC では左右パネルをフローティング表示したまま 3D を操作できる
- スマホでもオーバーレイ UI として使える

### Phase 3: ライブカメラ解析モード（初版実装）
- 画像解析パネルからカメラを起動できる
- プレビュー領域にライブ映像を表示できる
- ライブ映像を一定間隔で軽量解析し、PCCS カラータイルをリアルタイム更新できる
- 撮影ボタンでその瞬間のフレームを静止画像として確定できる
- 撮影後は通常の画像アップロード解析と同じフローへ合流する
- プレビューに見えている範囲と、ライブ解析 / 撮影範囲を一致させる crop を使っている
- スマホ向けに前面 / 背面カメラ切り替えを備える
- 権限拒否や取得失敗時は、画像解析パネル内に簡潔なエラーを表示する

## 3D ビュー操作

### 手動操作
- ドラッグ / スワイプで回転する
- 上下方向の操作でチルトする
- ホイール / ピンチでズームする
- 色点をクリック / タップすると色情報パネルを表示する

### 自動回転
- 自動回転は 1 つのボタンで `右回り → 左回り → OFF` を循環する
- ボタンの表示は回転方向に応じて変わる
- 手動操作中はいったん停止し、操作後に状態に応じて再開する

### 回転速度
- 設定モーダルから `回転速度` を調整できる
- 単位は `rpm`
- スライダーは左で遅く、右で速い
- 初期値は `1.0 rpm`（約 1 分で 1 周）
- 自動回転が OFF のときはスライダーは非活性になる
- 回転を再開すると、保持していた速度で再開する

### 球サイズ
- 設定モーダル最上部に `球サイズ` がある
- スライダーは左で小さく、右で大きい
- 初期値は現状サイズ（最大側）
- 選択中や強調中の球拡大は、通常球サイズに対する相対倍率で行うため、不自然に大きくなりにくい

### 基準方位固定
- 基準方位固定を ON にすると、PCCS の Y（イエロー）を基準にした方位へそろえたまま表示する
- ON 中は水平回転を固定し、チルトとズームはそのまま行える
- 自動回転とは排他的に扱う

## 補助線
- 補助線は設定モーダル内で個別に ON / OFF できる
- `同一トーン`
  - 各トーンの色相列を滑らかな閉曲線で結ぶ
- `同一色相`
  - 偶数番号色相ごとの縦曲線を表示する
- `同一明度`
  - 経線と高さ一定面の交点から作る水平断面線を表示する
- いずれもグラデーション付きの滑らかな曲線で、立体構造を読みやすくする目的で表示する

## 下部の色相ラベル
- 3D 表示下部の円周上ラベルは、PCCS の 24 色相を番号付きで表示する
- 例: `2:R`, `10:YG`, `24:RP`
- ラベルは円周に沿って配置され、3D 回転に追従する
- 現在の表示は以下の 24 色相を使う
  - `1:pR`
  - `2:R`
  - `3:yR`
  - `4:rO`
  - `5:O`
  - `6:yO`
  - `7:rY`
  - `8:Y`
  - `9:gY`
  - `10:YG`
  - `11:yG`
  - `12:G`
  - `13:bG`
  - `14:BG`
  - `15:BG`
  - `16:gB`
  - `17:B`
  - `18:B`
  - `19:pB`
  - `20:V`
  - `21:bP`
  - `22:P`
  - `23:rP`
  - `24:RP`

## 色相強調
- 色相強調ドロップダウンは番号付き表示を使う
  - 例: `14:BG（青緑）`
- 表示ラベルと内部値は分離している
- 内部判定は代表色相の一意な番号で厳密一致させている
- そのため、同じ記号を含む近接色相までまとめて強調しない
  - `14:BG` を選んでも `15:BG` 側は強調しない
  - `18:B` を選んでも `17:B` 側は強調しない

## 表示ラベルの扱い
- トーン強調 / 色相強調のドロップダウン表示は、日本語付きラベルで表示する
  - 例: `v（ビビッド）`
  - 例: `2:R（赤）`
- 表示用ラベル文字列は UTF-8 前提で管理する
- 内部値 `value` と表示文字列 `label` を分け、文字化けや判定の混線を避ける

## 色情報パネル
- 色点を選ぶと、画面右下または上部フローティング位置に色情報パネルを表示する
- 表示項目は以下
  - PCCS
  - Munsell
  - HEX
  - RGB
  - CMYK
- 各項目には個別のコピーボタンがある
- スマホでは折りたたみ表示に対応し、初期状態ではカラーバー中心の簡略表示になる
- スマホ版の開閉アイコンは、閉じているときに下向き、開いているときに上向きになるよう調整している
- 色帯には全画面カラーカードモードへの入口アイコンがあり、そこから選択色を画面全体で表示できる
- 色情報パネル上ではスワイプで近傍色へ移動できる
  - 左右: 同一トーン内で色相移動
  - 上下: 近いトーンへ移動
- 非表示から表示されるときだけ、選択球と色情報パネルを結ぶ接続ラインが球側から伸びる演出が入る
- パネル表示中は、線が選択中の球へ追従する
- 全画面カラーカードモード中に色を切り替えて戻った場合も、選択球・色情報パネル・接続ラインが同じ現在色へそろう
- 全画面カラーカードモード
  - 色情報パネルの色帯から入れる
  - 画面全体を現在の選択色で塗り、スマホでは端まで余白なく色面が届く見え方を優先している
  - 通常 UI は前面から外れ、`coloco` ロゴ、色名、戻る / 最小化ボタンだけを最小限で残す
  - safe area を考慮しつつ、背景色自体は画面端まで塗る
  - 全画面モード中も上下左右スワイプで既存ロジックのまま色移動できる
  - Safari など通常ブラウザでは、全画面モード中のスクロール干渉を抑える調整を入れている

## 複数選択強調
- 左上の専用トグルから、複数選択強調パネルを開ける
- PCCS 全色と無彩色 5 色の一覧から、複数色を直接選べる
- スマホでは単発タップで 1 マスずつ選択 / 解除できる
- スマホでは、少し長押ししてからドラッグすると連続選択 / 連続解除に入る
  - 最初に触れたタイルが未選択なら連続選択
  - 選択済みなら連続解除
  - 同一ドラッグ中に同じタイルを何度も反転しないよう制御している
  - 長押しせずに普通にドラッグした場合は、連続選択よりスクロール寄りの挙動を優先する
  - 長押しドラッグ中は、端へ寄せることで縦横どちらにも auto-scroll できる
- `全解除` で通常表示へ戻る
- `リストから選択` から、トーン → 色 ID の順で候補を開いて追加 / 解除できる
- 2 段目の色 ID 一覧はトグル式で、その場で複数色を連続選択できる
- 複数選択強調で 1 色でも操作すると、トーン強調 / 色相強調 / 画像解析強調は解除される
- 一方で、トーン強調 / 色相強調 / 画像解析強調を操作した時点で、その対象色集合は複数選択強調の選択状態にも裏側で同期される

## 画像解析の仕組み
- coloco の画像解析は、一般的な代表色抽出をしてから PCCS に寄せる方式ではない
- 画像内の各ピクセルを、最初から PCCS 161 色のどれかに直接分類している
- 解析前に画像を必要に応じて縮小する
- 小さい画像は無理に拡大しない
- 表示用サムネイルと解析用縮小画像は分けている
- 解析用縮小では通常の補間縮小で新しい中間色を作らず、縮小後ピクセルに対応する元画像領域の RGB 多数決で色を決める
- 各ピクセルと PCCS 各色の近さ判定には Lab 距離を使う
- この方式により、画像を「PCCS で読む」ための分類結果を、3D 色立体と同じ基準で見られる

## UI の見方
- 左上: 画像解析パネルの開閉
- 左上の画像解析トグル右: 複数選択強調パネルの開閉

- 上部中央: 仮ロゴ `coloco`
- 右下または上部フローティング: 色情報パネル
  - 色帯右側のアイコンから全画面カラーカードモードへ入れる
- 画像解析パネル
  - 画像アップロード / カメラ起動
  - リアルタイム解析タイル表示
  - `全選択 / 全解除`
- 複数選択強調パネル
  - `リストから選択`
  - `全解除`
  - 全色マトリクス直接選択
- 設定モーダル
  - トーン強調
  - 色相強調
  - 補助線表示
  - 球サイズ
  - 回転速度
  - 自動回転 / 基準方位固定
  - 初期化
  - トーン強調 / 色相強調のドロップダウンは、上下キーで候補を巡回できる

PC では画像解析パネルと複数選択強調パネルをフローティング表示し、背後の 3D を操作できる。  
スマホではオーバーレイ寄りの UI として扱う。

## データ構成
現在の PCCS 表示対象は合計 `161` 点です。
- `v` トーン: 24 色相 = 24 点
- その他 11 トーン: 12 色相代表 = 132 点
- 無彩色: 5 点

描画座標に使うのはマンセル値ではなく、PCCS 記号由来の明度・彩度です。
- 描画用
  - 色相
  - PCCS 明度
  - PCCS 彩度
- 表示用
  - HEX
  - RGB
  - CMYK
  - 色名
  - マンセル記号

## 座標の考え方
coloco の 3D 座標は、極座標ベースで次のように構成しています。
- 色相 = 角度
- PCCS 明度 = 縦軸
- PCCS 彩度 = 半径

概念式:

```ts
x = pccsSaturation * chromaScale * cos(theta)
z = pccsSaturation * chromaScale * sin(theta)
y = pccsLightness * verticalScale
```

- `theta` は 24 色相定義の `angleDeg` を使う
- 無彩色は `pccsSaturation = 0` として中心軸上に配置する
- 明度方向はわずかに強調し、彩度方向は少し抑えて、教材として読みやすいバランスにしている

## プロジェクト構成
主要なファイル / フォルダは以下です。
- `src/data`
  - PCCS 色相定義、有彩色点、無彩色点、表示色、データメモ
- `src/components`
  - 3D シーン、色点描画、色情報カード、強調表示 UI、画像解析パネル、複数選択強調パネル、仮ロゴ
- `src/utils/pccs3d.ts`
  - PCCS データから 3D 座標を計算
- `src/utils/highlight.ts`
  - 強調表示の判定ロジック
- `src/utils/color.ts`
  - RGB / Lab 変換と色距離計算
- `src/utils/imageClassification.ts`
  - 画像解析、PCCS 直接分類、分類結果の集計
- `src/utils/pccsNavigation.ts`
  - 色情報パネル上の移動ロジック
- `src/utils/persistence.ts`
  - LocalStorage 保存 / 復元ロジック
- `src/constants/viewConfig.ts`
  - カメラやスケール係数などの描画設定
- `src/App.tsx`
  - アプリ全体のレイアウトと状態管理

## ローカル保存
- coloco は LocalStorage を使ったローカル保存に対応している
- 保存対象の概要
  - 表示設定
  - 強調状態
  - 複数選択強調の選択集合
  - 3D ビューの向きやズーム
  - 画像解析パネルまわりの状態
- 画像そのものは保存せず、表示用サムネイル画像と解析用の小さい縮小画像を保存する
- 保存データには `version` を含め、JSON の破損や不足があった場合は安全に初期状態へフォールバックする

## 設定の初期化
- 右側設定モーダル左上に、消しゴムアイコンの初期化ボタンがある
- 初期化すると、設定・強調状態・画像解析状態・ローカル保存データをまとめて初期状態へ戻せる
- 初期化後は LocalStorage 側も更新されるため、リロード後も初期状態が維持される
