# coloco

coloco（カラコ）は、PCCS 色立体を 3D 空間で可視化し、色相・明度・彩度の関係を触りながら理解するための教材アプリです。  
現在の Phase 1 では、PCCS の有彩色 156 点と無彩色 5 点、合計 161 点を 3D の点群として表示するビューアを実装しています。

## Phase 1 でできること

- 3D 空間で PCCS 色立体を点群表示する
- ドラッグ / スワイプによる回転
- 上下操作によるチルト
- ホイール / ピンチによるズーム
- 色点の選択と色情報表示
- トーン / 色相 / 無彩色の強調表示
- PC / スマホのレスポンシブ対応

## データ構成

Phase 1 の表示対象は合計 `161` 点です。

- `v` トーン: 24 色相 = 24 点
- その他 11 トーン: 12 色相代表 = 132 点
- 無彩色: 5 点

Phase 1 では、`v` は 24 色相、その他 11 トーンは 12 色相代表で扱う代表構成を採用しています。

描画座標に使うのはマンセル値ではなく、PCCS 記号由来の明度・彩度です。

- 描画用
  - 色相
  - PCCS 明度
  - PCCS 彩度
- 表示用
  - HEX
  - RGB
  - 色名
  - マンセル記号

マンセル記号は情報表示用の補助データとして保持しており、座標計算には使いません。

## 座標の考え方

coloco の 3D 座標は、極座標ベースで次のように構成しています。

- 色相 = 角度
- PCCS 明度 = 縦軸
- PCCS 彩度 = 半径

概念式:

```ts
x = pccsSaturation * chromaScale * cos(theta)
z = pccsSaturation * chromaScale * sin(theta)
y = pccsLightness * verticalScale
```

- `theta` は 24 色相定義の `angleDeg` を使う
- 無彩色は `pccsSaturation = 0` として中心軸上に配置する
- 表示色には `hex / rgb` を使う

## 使い方

- ドラッグ / スワイプで色立体を回転
- 上下方向の操作でチルト
- マウスホイール / ピンチでズーム
- 色点をクリック / タップすると色情報カードを表示
- 強調表示 UI でトーン / 色相 / 無彩色を切り替え

初期状態では色立体がゆっくり自動回転し、操作中は停止、操作終了後に再開します。

## プロジェクト構成

主要なファイル / フォルダは以下です。

- `src/data`
  - PCCS 色相定義、有彩色点、無彩色点、表示色、データメモ
- `src/components`
  - 3D シーン、色点描画、色情報カード、強調表示 UI
- `src/utils/pccs3d.ts`
  - PCCS データから 3D 座標を計算
- `src/utils/highlight.ts`
  - 強調表示の判定ロジック
- `src/constants/viewConfig.ts`
  - カメラやスケール係数などの描画設定
- `src/App.tsx`
  - アプリ全体のレイアウトと状態管理
